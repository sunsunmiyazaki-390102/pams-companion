# PAMS Companion

## Project

PAMS Companion は、

生成AIをより便利に、より安全に、より継続的に利用するための

**AI利用支援プラットフォーム**

です。

---

## PAMS Platform

PAMS Platform は次の3つのプロジェクトで構成されます。

- PAMS Specification
- PAMS Manager
- PAMS Companion

本リポジトリは、

一般利用者向け製品である

**PAMS Companion**

を管理します。

---

## Purpose

PAMS Companion は、

AIを賢くすることではなく、

利用者がAIをより賢く使えるよう支援することを目的としています。
