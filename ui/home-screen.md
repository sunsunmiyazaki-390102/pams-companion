# 1. 画面の目的

ホーム画面は、利用者がPAMS Companionを起動した後、次に行う操作を迷わず選択するための入口とする。

専門用語を使用せず、主要な操作を大きなボタンで表示する。

# 3. 表示項目

## 3.1 タイトル

表示内容：

```text
PAMS Companion
```

## 3.2 案内文

表示内容：

```text
今日は何をしますか？
```

## 3.3 メニューボタン

次の5つを表示する。

1. AIに相談する
2. AIの回答を整理する
3. 今日の記憶
4. プロジェクト
5. 設定

---

# 4. ボタンの動作

| ボタン | 遷移先 |
|---|---|
| AIに相談する | AIへの質問作成画面 |
| AIの回答を整理する | AI回答入力・整理画面 |
| 今日の記憶 | 当日の知識資産候補一覧 |
| プロジェクト | プロジェクト一覧 |
| 設定 | 利用者設定画面 |

---

# 5. UX方針

- スマートフォンで片手操作しやすいこと
- ボタンを縦方向に並べること
- ボタンの文字を大きく表示すること
- 説明を読まなくても操作が分かること
- 一画面に情報を詰め込み過ぎないこと
- 最も利用頻度が高い「AIに相談する」を最上部に配置すること

---

# 6. MVPで実装しない内容

ホーム画面の初期実装では、次の内容は表示しない。

- 利用状況のグラフ
- 成長度の表示
- お知らせ
- AIからの自動提案
- カレンダー
- 詳細な統計情報

必要性を確認した後に追加を検討する。

---

# 7. 完了条件

ホーム画面は、次の状態になればMVPとして完成とする。

1. 5つのメニューボタンが表示される
2. スマートフォン幅で正しく表示される
3. 各ボタンを押すと対応する画面へ遷移できる
4. 初めて利用する人でも次の操作を理解できる
